**Excursion**
- A simple landing page built as part of Codecademy’s Excursion project. 
The page promotes a fictional mobile app that helps users discover hidden places around the world.

**Features**
- Responsive layout
- Embedded promotional video
- Images showcasing the app concept
  
**Project Goal**
- This project reinforces fundamentals of front‑end development, including layout, linking assets, and separating structure from style.

**Tech Stack**
- Frontend: HTML5, CSS3
- Version Control: Git, GitHub
- Tools: Bash, VS Code
